# 第一章 · 方程组

线性代数从最朴素的问题开始：**几个线性方程放在一起，解长什么样？**

如果只有两个未知数，每个方程都是一条直线，解就是直线的交点；到了三个未知数，方程变成平面，解就是平面的交线或交点。这一章把这个几何直觉逐步翻译成一套代数语言：增广矩阵、行化简、主元。学完之后，你会得到一个可以处理任意多个方程与未知数的算法，而不只是会画两条线。

::: tip 阅读建议
本章的四个小节是有依赖的：1.1 建立直觉，1.2 给出算法，1.3 让你在计算机上验证它，1.4 用主元统一解释「什么时候有解、解是否唯一」。如果时间有限，至少完整读 1.2 与 1.4。
:::

## 学完这一章，你应该能够

- 说清楚一个线性系统的解集为什么只可能是空集、单点或无穷集合；
- 独立完成高斯消元，并把矩阵化为简化行阶梯形（RREF）；
- 从 RREF 直接读出解集，包括自由变量与参数化写法；
- 判断一个系统是否相容、何时解唯一，并用主元位置解释原因；
- 用 Sage 复现上述计算，检查手算结果。
