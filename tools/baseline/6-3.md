# 6.3 Orthogonal bases and projections

We know that a linear system $A\xvec=\bvec$ is inconsistent when $\bvec$ is not in $\col(A)$, the column space of $A$. Later in this chapter, we'll develop a strategy for dealing with inconsistent systems by finding $\bhat$, the vector in $\col(A)$ that minimizes the distance to $\bvec$. The equation $A\xvec=\bhat$ is therefore consistent and its solution set can provide us with useful information about the original system $A\xvec=\bvec$.

In this section and the next, we'll develop some techniques that enable us to find $\bhat$, the vector in a given subspace $W$ that is closest to a given vector $\bvec$.

We frequently ask to write a given vector as a linear combination of given basis vectors. In the past, we have done this by solving a linear system. The preview activity illustrates how this task can be simplified when the basis vectors are orthogonal to each other. We'll explore this and other uses of orthogonal bases in this section.

The preview activity dealt with a basis of $\real^2$ formed by two orthogonal vectors. More generally, we will consider a set of orthogonal vectors, as described in the next definition.

<a id="6-3-definition-1" class="ula-anchor"></a>

:::::: definition 定义 6.3.1

By an *orthogonal set* of vectors, we mean a set of nonzero vectors each of which is orthogonal to the others.

::::::

<a id="example-orthogonal-basis" class="ula-anchor"></a>

:::::: example 例 6.3.1

The 3-dimensional vectors 

$$
\begin{aligned}
\wvec_1 = \threevec1{-1}1,\hspace{24pt}
\wvec_2 = \threevec1{1}0,\hspace{24pt}
\wvec_3 = \threevec1{-1}{-2}.
\end{aligned}
$$

 form an orthogonal set, which can be verified by computing 

$$
\begin{array}{rcl}
\wvec_1\cdot\wvec_2 & {}={} & 0 \\
\wvec_1\cdot\wvec_3 & {}={} & 0 \\
\wvec_2\cdot\wvec_3 & {}={} & 0\text{.} \\
\end{array}
$$

 Notice that this set of vectors forms a basis for $\real^3$.

::::::

<a id="example-orthogonal-set" class="ula-anchor"></a>

:::::: example 例 6.3.2

The vectors 

$$
\begin{aligned}
\wvec_1 = \fourvec1111,\hspace{24pt}
\wvec_2 = \fourvec11{-1}{-1},\hspace{24pt}
\wvec_3 = \fourvec1{-1}1{-1}
\end{aligned}
$$

 form an orthogonal set of 4-dimensional vectors. Since there are only three vectors, this set does not form a basis for $\real^4$. It does, however, form a basis for a 3-dimensional subspace $W$ of $\real^4$.

::::::

Suppose that a vector $\bvec$ is a linear combination of an orthogonal set of vectors $\wvec_1,\wvec_2,\ldots,\wvec_n$; that is, suppose that 

$$
\begin{aligned}
c_1\wvec_1 + c_2\wvec_2 + \cdots + c_n\wvec_n = \bvec.
\end{aligned}
$$

 Just as in the preview activity, we can find the weight $c_1$ by dotting both sides with $\wvec_1$ and applying the distributive property of dot products: 

$$
\begin{aligned}
(c_1\wvec_1 + c_2\wvec_2 + \cdots + c_n\wvec_n)\cdot\wvec_1
& = \bvec\cdot\wvec_1


c_1\wvec_1\cdot\wvec_1 + c_2\wvec_2\cdot\wvec_1 +\cdots +
c_n\wvec_n\cdot\wvec_1 & = \bvec\cdot\wvec_1


c_1\wvec_1\cdot\wvec_1 & = \bvec\cdot\wvec_1


c_1 & =
\frac{\bvec\cdot\wvec_1}{\wvec_1\cdot\wvec_1}\text{.}
\end{aligned}
$$

 Notice how the presence of an orthogonal set causes most of the terms in the sum to vanish. In the same way, we find that 

$$
\begin{aligned}
c_i = \frac{\bvec\cdot\wvec_i}{\wvec_i\cdot\wvec_i}
\end{aligned}
$$

 so that 

$$
\begin{aligned}
\bvec = \frac{\bvec\cdot\wvec_1}{\wvec_1\cdot\wvec_1}\wvec_1 +
\frac{\bvec\cdot\wvec_2}{\wvec_2\cdot\wvec_2}\wvec_2 +
\cdots +
\frac{\bvec\cdot\wvec_n}{\wvec_n\cdot\wvec_n}\wvec_n\text{.}
\end{aligned}
$$

We'll record this fact in the following proposition.

<a id="prop-orthog-lincomb" class="ula-anchor"></a>

:::::: proposition 命题 6.3.1

If a vector $\bvec$ is a linear combination of an orthogonal set of vectors $\wvec_1,\wvec_2,\ldots,\wvec_n$, then 

$$
\begin{aligned}
\bvec = \frac{\bvec\cdot\wvec_1}{\wvec_1\cdot\wvec_1}\wvec_1 +
\frac{\bvec\cdot\wvec_2}{\wvec_2\cdot\wvec_2}\wvec_2 +
\cdots +
\frac{\bvec\cdot\wvec_n}{\wvec_n\cdot\wvec_n}\wvec_n\text{.}
\end{aligned}
$$

::::::

Using this proposition, we can see that an orthogonal set of vectors must be linearly independent. Suppose, for instance, that $\wvec_1,\wvec_2,\ldots,\wvec_n$ is a set of nonzero orthogonal vectors and that one of the vectors is a linear combination of the others, say, 

$$
\begin{aligned}
\wvec_3 = c_1\wvec_1 + c_2\wvec_2\text{.}
\end{aligned}
$$

 We therefore know that 

$$
\begin{aligned}
\wvec_3 =
\frac{\wvec_3\cdot\wvec_1}{\wvec_1\cdot\wvec_1}\wvec_1 +
\frac{\wvec_3\cdot\wvec_2}{\wvec_2\cdot\wvec_2}\wvec_2
= \zerovec\text{,}
\end{aligned}
$$

 which cannot happen since we know that $\wvec_3$ is nonzero. This tells us that

<a id="prop-orthog-lin-indep" class="ula-anchor"></a>

:::::: proposition 命题 6.3.2

An orthogonal set of vectors $\wvec_1,\wvec_2,\ldots,\wvec_n$ is linearly independent.

::::::

If the vectors in an orthogonal set have dimension $m$, they form a linearly independent set in $\real^m$ and are therefore a basis for the subspace $W=\laspan{\wvec_1,\wvec_2,\ldots,\wvec_n}$. If there are $m$ vectors in the orthogonal set, they form a basis for $\real^m$.

This activity introduces an important way of modifying an orthogonal set so that the vectors in the set have unit length. Recall that we may multiply any nonzero vector $\wvec$ by a scalar so that the new vector has length 1. For instance, we know that if $s$ is a positive scalar, then $\len{s\wvec} = s\len{\wvec}$. To obtain a vector $\uvec$ having unit length, we want 

$$
\begin{aligned}
\len{\uvec} = \len{s\wvec} = s\len{\wvec} = 1
\end{aligned}
$$

 so that $s=1/\len{\wvec}$. Therefore, 

$$
\begin{aligned}
\uvec = \frac{1}{\len{\wvec}}\wvec
\end{aligned}
$$

 becomes a unit vector parallel to $\wvec$.

Orthogonal sets in which the vectors have unit length are called *orthonormal* and are especially convenient.

<a id="6-3-definition-2" class="ula-anchor"></a>

:::::: definition 定义 6.3.2

An *orthonormal* set is an orthogonal set of vectors each of which has unit length.

::::::

<a id="6-3-example-3" class="ula-anchor"></a>

:::::: example 例 6.3.3

The vectors 

$$
\begin{aligned}
\uvec_1=\twovec{1/\sqrt{2}}{1/\sqrt{2}},\hspace{24pt}
\uvec_2=\twovec{-1/\sqrt{2}}{1/\sqrt{2}}
\end{aligned}
$$

 are an orthonormal set of vectors in $\real^2$ and form an orthonormal basis for $\real^2$.

If we form the matrix 

$$
Q=\begin{bmatrix}
\uvec_1 & \uvec_2
\end{bmatrix}
= \begin{bmatrix}
1/\sqrt{2} & -1/\sqrt{2} \\
1/\sqrt{2} & 1/\sqrt{2} \\
\end{bmatrix}\text{,}
$$

 we find that $Q^TQ = I$ since [命题 6.2.1](/chapter-6/6-2#prop-transpose-multiplication) tells us that 

$$
Q^TQ = \begin{bmatrix}

\uvec_2\cdot\uvec_1 & \uvec_2\cdot\uvec_2 \\
\end{bmatrix}
=
\begin{bmatrix}
1 & 0 \\
0 & 1 \\
\end{bmatrix}
$$

In all the cases considered in the activity, we are looking for $\bhat$, the vector in a subspace $W$ closest to a vector $\bvec$, which is found by requiring that $\bvec-\bhat$ be orthogonal to $W$. This means that $(\bvec-\bhat)\cdot\wvec = 0$ for any vector $\wvec$ in $W$.

If we have an orthogonal basis $\wvec_1,\wvec_2,\ldots,\wvec_n$ for $W$, then $\bhat = c_1\wvec_1+c_w\wvec_2+\cdots+c_n\wvec_n$. Therefore, 

$$
\begin{aligned}
(\bvec-\bhat)\cdot\wvec_i & = 0


\bvec\cdot\wvec_i & = \bhat\cdot\wvec_i


\bvec\cdot\wvec_i & =
(c_1\wvec_1+c_2\wvec_2+\cdots + c_n\wvec_n)\cdot\wvec_i


\bvec\cdot\wvec_i & = c_i\wvec_i\cdot\wvec_i


c_i & = \frac{\bvec\cdot\wvec_i}{\wvec_i\cdot\wvec_i}.
\end{aligned}
$$

 This leads to the projection formula:

<a id="prop-proj-formula" class="ula-anchor"></a>

:::::: proposition 命题 6.3.4 · Projection formula

If $W$ is a subspace of $\real^m$ having an orthogonal basis $\wvec_1,\wvec_2,\ldots, \wvec_n$ and $\bvec$ is a vector in $\real^m$, then the orthogonal projection of $\bvec$ onto $W$ is 

$$
\begin{aligned}
\bhat=
\frac{\bvec\cdot\wvec_1}{\wvec_1\cdot\wvec_1}~\wvec_1 +
\frac{\bvec\cdot\wvec_2}{\wvec_2\cdot\wvec_2}~\wvec_2 +
\cdots +
\frac{\bvec\cdot\wvec_n}{\wvec_n\cdot\wvec_n}~\wvec_n\text{.}
\end{aligned}
$$

::::::

:::::: note Caution

Remember that the projection formula given in [命题 6.3.4](/chapter-6/6-3#prop-proj-formula) applies only when the basis $\wvec_1,\wvec_2,\cdots,\wvec_n$ of $W$ is *orthogonal*.

::::::

If we have an orthonormal basis $\uvec_1,\uvec_2,\ldots,\uvec_n$ for $W$, the projection formula simplifies to 

$$
\begin{aligned}
\bhat=
(\bvec\cdot\uvec_1)~\uvec_1 +
(\bvec\cdot\uvec_2)~\uvec_2 +
\cdots +
(\bvec\cdot\uvec_n)~\uvec_n\text{.}
\end{aligned}
$$

 If we then form the matrix 

$$
Q =
\begin{bmatrix}
\uvec_1 & \uvec_2 & \ldots & \uvec_n
\end{bmatrix}\text{,}
$$

 this expression may be succintly written 

$$
\begin{aligned}
\bhat & {}={}
(\bvec\cdot\uvec_1)~\uvec_1 +
(\bvec\cdot\uvec_2)~\uvec_2 +
\cdots +
(\bvec\cdot\uvec_n)~\uvec_n


& {}={}
\begin{bmatrix}
\uvec_1&\uvec_2&\ldots&\uvec_n
\end{bmatrix}
\begin{bmatrix}
\uvec_1\cdot\bvec \\
\uvec_2\cdot\bvec \\
\vdots \\
\uvec_n\cdot\bvec \\
\end{bmatrix}


& {}={} QQ^T\bvec
\end{aligned}
$$

This leads to the following proposition.

<a id="prop-proj-orthonormal" class="ula-anchor"></a>

:::::: proposition 命题 6.3.5

If $\uvec_1,\uvec_2,\ldots,\uvec_n$ is an orthonormal basis for a subspace $W$ of $\real^m$, then the matrix transformation that projects vectors in $\real^m$ orthogonally onto $W$ is represented by the matrix $P=QQ^T$ where 

$$
Q =
\begin{bmatrix}
\uvec_1 & \uvec_2 & \ldots & \uvec_n \\
\end{bmatrix}\text{.}
$$

This activity demonstrates one issue of note. We found $\bhat$, the orthogonal projection of $\bvec$ onto $W$, by requiring that $\bvec-\bhat$ be orthogonal to $W$. In other words, $\bvec-\bhat$ is a vector in the orthogonal complement $W^\perp$, which we may denote $\bvec^\perp$. This explains the following proposition, which is illustrated in [图 6.3.4](/chapter-6/6-3#fig-orthog-decomp)

<a id="prop-orthog-decomp" class="ula-anchor"></a>

:::::: proposition 命题 6.3.6

If $W$ is a subspace of $\real^n$ with orthogonal complement $W^\perp$, then any $n$-dimensional vector $\bvec$ can be uniquely written as 

$$
\begin{aligned}
\bvec = \bhat + \bvec^\perp
\end{aligned}
$$

 where $\bhat$ is in $W$ and $\bvec^\perp$ is in $W^\perp$. The vector $\bhat$ is the orthogonal projection of $\bvec$ onto $W$ and $\bvec^\perp$ is the orthogonal projection of $\bvec$ onto $W^\perp$.

::::::

Let's summarize what we've found. If $Q$ is a matrix whose columns $\uvec_1, \uvec_2,\ldots,\uvec_n$ form an orthonormal set in $\real^m$, then 

- $Q^TQ = I_n$, the $n\times n$ identity matrix, because this product computes the dot products between the columns of $Q$.
- $QQ^T$ is the matrix the projects vectors orthogonally onto $W$, the subspace of $\real^m$ spanned by $\uvec_1,\ldots,\uvec_n$.

 As we've said before, matrix multiplication depends on the order in which we multiply the matrices, and we see this clearly here.

Because $Q^TQ=I$, there is a temptation to say that $Q$ is invertible. This is usually not the case, however. Remember that an invertible matrix must be a square matrix, and the matrix $Q$ will only be square if $n=m$. In this case, there are $m$ vectors in the orthonormal set so the subspace $W$ spanned by the vectors $\uvec_1,\uvec_2,\ldots,\uvec_m$ is $\real^m$. If $\bvec$ is a vector in $\real^m$, then $\bhat=QQ^T\bvec$ is the orthogonal projection of $\bvec$ onto $\real^m$. In other words, $QQ^T\bvec$ is the closest vector in $\real^m$ to $\bvec$, and this closest vector must be $\bvec$ itself. Therefore, $QQ^T\bvec = \bvec$, which means that $QQ^T=I$. In this case, $Q$ is an invertible matrix.

:::::: example 例 6.3.5

Consider the orthonormal set of vectors 

$$
\begin{aligned}
\uvec_1=\threevec{1/\sqrt{3}}{-1/\sqrt{3}}{1/\sqrt{3}},
\hspace{24pt}
\uvec_2=\threevec{1/\sqrt{2}}{1/\sqrt{2}}0
\end{aligned}
$$

 and the matrix they define 

$$

 In this case, $\uvec_1$ and $\uvec_2$ span a plane, a 2-dimensional subspace of $\real^3$. We know that $Q^TQ = I_2$ and $QQ^T$ projects vectors orthogonally onto the plane. However, $Q$ is not a square matrix so it cannot be invertible.

<a id="6-3-example-6" class="ula-anchor"></a>

:::::: example 例 6.3.6

Now consider the orthonormal set of vectors 

$$
\begin{aligned}
\uvec_1=\threevec{1/\sqrt{3}}{-1/\sqrt{3}}{1/\sqrt{3}},
\hspace{24pt}
\uvec_2=\threevec{1/\sqrt{2}}{1/\sqrt{2}}0,
\hspace{24pt}
\uvec_3=\threevec{1/\sqrt{6}}{-1/\sqrt{6}}{-2/\sqrt{6}}
\end{aligned}
$$

 and the matrix they define 

$$
Q = \begin{bmatrix}
1/\sqrt{3} & 1/\sqrt{2} & 1/\sqrt{6} \\
-1/\sqrt{3} & 1/\sqrt{2} & -1/\sqrt{6} \\
1/\sqrt{3} & 0 & -2/\sqrt{6} \\
\end{bmatrix}\text{.}
$$

 Here, $\uvec_1$, $\uvec_2$, and $\uvec_3$ form a basis for $\real^3$ so that both $Q^TQ=I_3$ and $QQ^T=I_3$. Therefore, $Q$ is a square matrix and is invertible.

Moreover, since $Q^TQ = I$, we see that $Q^{-1} =
Q^T$ so finding the inverse of $Q$ is as simple as writing its transpose. Matrices with this property are very special and will play an important role in our upcoming work. We will therefore give them a special name.

::::::

<a id="6-3-definition-4" class="ula-anchor"></a>

:::::: definition 定义 6.3.4

A square $m\times m$ matrix $Q$ whose columns form an orthonormal basis for $\real^m$ is called *orthogonal*.

::::::

This terminology can be a little confusing. We call a basis orthogonal if the basis vectors are orthogonal to one another. However, a matrix is orthogonal if the columns are orthogonal to one another and have unit length. It pays to keep this in mind when reading statements about orthogonal bases and orthogonal matrices. In the meantime, we record the following proposition.

<a id="prop-orthog-matrix" class="ula-anchor"></a>

:::::: proposition 命题 6.3.7

An orthogonal matrix $Q$ is invertible and its inverse $Q^{-1} = Q^T$.

::::::

This section introduced orthogonal sets and the projection formula that allows us to project vectors orthogonally onto a subspace. 

- Given an orthogonal set $\wvec_1,\wvec_2,\ldots,\wvec_n$ that spans an $n$-dimensional subspace $W$ of $\real^m$, the orthogonal projection of $\bvec$ onto $W$ is the vector in $W$ closest to $\bvec$ and may be written as 
 
 $$
 \begin{aligned}
 \bhat =
 \frac{\bvec\cdot\wvec_1}{\wvec_1\cdot\wvec_1}~\wvec_1 +
 \frac{\bvec\cdot\wvec_2}{\wvec_2\cdot\wvec_2}~\wvec_2 +
 \cdots +
 \frac{\bvec\cdot\wvec_n}{\wvec_n\cdot\wvec_n}~\wvec_n\text{.}
 \end{aligned}
 $$
- If $\uvec_1,\uvec_2,\ldots,\uvec_n$ is an orthonormal basis of $W$ and $Q$ is the matrix whose columns are $\uvec_i$, then the matrix $P=QQ^T$ projects vectors orthogonally onto $W$.
- If the columns of $Q$ form an orthonormal basis for an $n$-dimensional subspace of $\real^m$, then $Q^TQ=I_n$.
- An orthogonal matrix $Q$ is a square matrix whose columns form an orthonormal basis. In this case, $QQ^T=Q^TQ = I$ so that $Q^{-1} = Q^T$.
