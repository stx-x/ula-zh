# 第五章 · 线性代数与计算

我们求解线性方程组的主要工具一直是高斯消元，我们在[第 1 章](/chapter-1/)首次接触它。面对一个线性方程组时，我们常常求出其增广矩阵的简化行阶梯形，以读出解。虽然这对学习线性代数是一种便利的方法，但人们很少使用矩阵的简化行阶梯形。事实上，许多线性代数软件包并不包含求简化行阶梯形的函数。在本章中，我们将说明为什么会这样，然后探索一些替代方法。本章的目的是展示线性代数计算在实践中是如何进行的。更具体地说，我们将改进通过高斯消元求解线性方程组和求特征向量的技术。
