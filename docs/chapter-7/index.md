# 第七章 · 奇异值分解

上一章展示了特征值与特征向量理论的几个重要用途。例如，知道矩阵 $A$ 的特征值与特征向量，使我们能够预测动力系统的长期行为，其中某个初始状态 $\xvec_0$ 按 $\xvec_{k+1} = A\xvec_k$ 演化。然而，我们不能把这一理论应用于可能遇到的每一个问题。首先，特征向量只在 $A$ 为方阵时存在，而我们已经看到一些情形（例如[第 6 章](/chapter-6/)中的最小二乘问题），其中我们关心的矩阵不是方阵。其次，即使 $A$ 是方阵，也可能不存在由 $A$ 的特征向量组成的 $\real^m$ 的基，而这是我们先前的某些工作所需要的重要条件。本章介绍奇异值分解，它的奇异值与奇异向量可以看作特征值与特征向量的推广。事实上，我们将看到每个矩阵——无论是否为方阵——都有奇异值分解，而知道它会让我们对矩阵有深入的理解。有人说，拥有奇异值分解就像用 X 射线看矩阵，因为分解揭示了矩阵的本质特征。
