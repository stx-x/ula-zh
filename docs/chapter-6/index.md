# 第六章 · 正交性与最小二乘

我们引入向量，是为了对关于线性方程组的基本问题建立直观理解。例如，向量使我们能够把关于线性方程组解的存在性的问题，重新表述为关于向量组的张成的问题。关于解的唯一性的问题引出了线性无关的概念。在本章中，我们将开始把向量视为具有长度并形成夹角的几何对象。在某些情况下，这将简化我们寻找线性方程组解的过程。也许更重要的是，我们将能够度量向量之间的距离。这意味着，如果方程组 $A\xvec=\bvec$ 不相容，我们可以寻找 $\xhat$，使得 $A\xhat$ 尽可能接近 $\bvec$。这引出了最小二乘法，它支撑着回归——数据科学中的一个关键工具。
