# 第三章 · 可逆性、基与坐标系

在[第 2 章](/chapter-2/)中，我们分别独立地考察了关于线性方程组解的存在性与唯一性的[两个基本问题](/chapter-1/1-4#fundamental-questions)。我们发现，当 $A$ 的列的张成是 $\real^m$ 时，每个形如 $A\xvec = \bvec$ 的方程都有解。我们还发现，当 $A$ 的列线性无关时，齐次方程 $A\xvec = \zerovec$ 的解 $\xvec=\zerovec$ 是唯一的。在本章中，我们探索这两个条件同时成立的情形。
